Connect with a public URL

                
Keep the HTTPS endpoint private because it contains your access token.

                
ChatGPT
In ChatGPT on the web, go to Plugins → Add custom MCP server. Select Server URL, paste the endpoint, choose No authentication for this tokenized URL, and create the plugin. Your workspace policy may restrict access.

                
Claude
Open Customize → Connectors → Add custom connector, then paste the endpoint. In Claude Code, run claude mcp add --transport http omnidev_studio <URL>.

                
Gemini CLI
Add omnidev_studio under mcpServers in ~/.gemini/settings.json. Set httpUrl to the copied endpoint and reload MCP servers.

Custom Skills & Plugins

              
JavaScript plugins extend OmniDev with MCP tools and reload when their files change.

              

              

              
Write a plugin
Add a .js file to the plugins folder. Export a unique name, description, JSON Schema inputSchema, and a handler. Use isCritical: true for tools that should require approval in Smart mode. Install plugins you trust.
